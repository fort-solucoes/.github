# Fort Serviços

Automação de atendimento e operações com agentes de voz e IA — chamadas outbound, monitoramento de campo e fluxos de negociação.

## O que fazemos

Construímos Soluções para problemas modernos utilizando IA, como:

- Cobrança e negociação outbound
- Monitoramento de tempo de atendimento em campo (instalação, suporte técnico)
- Notificações e resumos automáticos via WhatsApp

## Como está organizado

| Repositório | Descrição |
|---|---|
| `fort-agents-core` | Biblioteca compartilhada — sessão Agora, retry, autenticação |
| `fort-agent-*` | Um repositório por agente em produção |
| `painel-gerenciamento` | Dashboard web de monitoramento e logs |

## Stack

Python · PostgreSQL · Agora ConvoAI Engine · WhatsApp Business API
